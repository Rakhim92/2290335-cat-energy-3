# Личный проект «Кэт энерджи»
Описание: Проект является интернет-магазином кошачьего корма. Состоит из двух страниц: главной страницы и страницы каталога.
Адаптивность сетки: мобильная, планшетная и десктопная версии («фикс»).
Адаптивность графики: ретинизация, векторные изображения.
Используемая методология: БЭМ.
Используемый препроцессор: Sass.
Используемый инструмент автоматизации: Gulp.
Используемые библиотеки: нет.
Кроссбраузерность: Chrome, Firefox, Safari.
Используемый шрифт: Oswald, Lato.
